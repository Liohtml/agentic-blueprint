# Contributing to Agentic Blueprint

Thank you for your interest in contributing! This project is a community-driven framework for autonomous AI-assisted engineering workflows.

## How to Contribute

### Reporting Issues
- Use GitHub Issues to report bugs or suggest improvements
- Include which phase, agent role, or template is affected
- Describe what you expected vs. what happened

### Suggesting Improvements
- Open a GitHub Issue with the label `enhancement`
- Describe the problem your improvement solves
- If possible, reference your experience using the blueprint in a real project

### Submitting Changes

1. **Fork** the repository
2. **Create a branch** from `main`: `git checkout -b improve/phase-2-prompt`
3. **Make your changes** — keep them focused on one area
4. **Test your changes** by using the modified blueprint in an actual project
5. **Submit a Pull Request** with a clear description of what changed and why

### What We're Looking For

- **Better prompt templates** — if you found a prompt that works better in a specific phase, share it
- **New agent profiles** — if you use a different AI tool (not just Claude Code / Antigravity), add a profile for it
- **Loop limit adjustments** — if you have data showing different iteration limits work better
- **Translations** — the blueprint content is currently in German; translations are welcome
- **Real-world retros** — anonymized retrospectives from actual projects help everyone calibrate

### What We're NOT Looking For

- Changes that add complexity without clear benefit
- Vendor-specific lock-in (the blueprint should stay harness-agnostic in its principles)
- Marketing language or promotional content

## Code of Conduct

Be respectful, constructive, and focused on making the blueprint better for everyone.

## Questions?

Open an issue with the label `question` — we're happy to help.
